## Pattern Extraction Rules

- Capture page intent before visual style.
- Prefer reusable sections over full-page cloning.
- Record the source URL and why it is useful.
- Track complexity so small MVPs do not inherit overbuilt launch-page patterns.
- Include implementation notes next to visual notes.
- Use local CSS previews first; add screenshots later only when rights and storage
  are clear.
